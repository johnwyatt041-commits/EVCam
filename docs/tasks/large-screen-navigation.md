# 大屏侧栏触控优化

用户屏幕为 2560×1600，反馈侧边选项太小、不好按。任务基线 `dba5808`，串行分支 `codex/large-screen-navigation`。本次仅调整共用界面，A/B 录像方案继续保留。

## 调整

- 原侧栏 76/96dp，按钮固定 64dp、文字 13sp、图标 24dp。
- 改成按最小宽度和可用高度分档的资源；大屏侧栏宽 160/184/208dp，按钮最小高 88/112/144dp，文字 22/26/30sp，图标 36/44/52dp。紧凑屏保留 112dp 侧栏和至少 80dp 按钮。
- 点击范围覆盖整块按钮；六项入口和选中状态不变。图标只在 AppShell 的六个入口设置尺寸，不放大其他功能共用的图标资源。
- 按钮高度可随系统字体增长，侧栏可滚动；以逻辑 dp 与可用高度适配，不假设 2560×1600 一定对应某个系统 DPI。
- 没有扩大整页字体、增加常驻任务或修改摄像头/录像/HUD/补盲逻辑。
